# Quintenzirkel & Stufen

Interaktiver Quintenzirkel mit deutschen Bezeichnungen (H, B, Fis, Es …).

- **Außenring:** Tonarten im Quintenzirkel inkl. Paralleltonart – wischen zum Drehen, antippen zum Wählen, nochmals antippen für enharmonische Umdeutung (z. B. Fis ↔ Ges).
- **Innenringe:** Töne, Dreiklänge (mit Stufe), Septakkorde und Modi (mit Tönen und Intervallformel) der gewählten Tonart.
- **Systeme:** Dur, harmonisch Moll, melodisch Moll, harmonisch Dur.
- **Hören:** Dreiklang, Septakkord, Modus und Tonleiter per Web Audio abspielen.

Eine einzelne statische `index.html`, kein Build nötig.

Live: https://matt-hires.github.io/quintenzirkel/
